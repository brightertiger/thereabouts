# Historical serving format

Format 1 and its Python/JavaScript readers are retired. The historical
specification remains in Git at commit 3ade5da. The current clients reject old
packs; they do not silently convert them.

[PACK_FORMAT.md](PACK_FORMAT.md) is the single normative specification for
format 2.2. See [CLI.md](CLI.md) for installation, store and transport contracts.
